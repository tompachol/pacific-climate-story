# Pacific Climate Story SvelteKit scaffold

Ten zestaw zawiera prosty szkielet scrollytellingu w SvelteKit oraz listę proponowanych plików danych.

## Co dalej
1. Zainstaluj zależności.
2. Podmień placeholdery na prawdziwe wykresy i mapę.
3. Dodaj dane CSV/JSON do `src/lib/data/`.
4. Rozbij jedną stronę na komponenty.
